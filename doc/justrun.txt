JustRun.nvim                                                     *justrun.nvim*

A simple, flexible, and powerful task runner for Neovim. Define your project
tasks in a local Lua file and run them easily inside a terminal buffer.


===============================================================================
                                                                *justrun-usage*
1. Usage ~

Create a file named `.justrun.lua` in your project root.

Minimal example: >lua
    return {
        default = "echo 'Hello World'",
        test = "npm test"
    }
<

Complex example with type hinting: >lua
    local justrun = require("justrun")

    return justrun.create_tasks({
        default = {
            run_before = {"build"}, -- Run task build before the cmd
            cmd = "./main",
            cwd = "./src"
        },

        -- Default Separator (&&)
        -- Resulting command: echo 'Hello, ' && echo 'world!'
        greet = {"echo 'Hello, '", "echo 'world!'"},

        -- Create a custom task to python filetype. See more: |ftplugin-docs|
        python = {
            cmd = "python main.py",
            desc = "Run the main.py"
        },

        -- Placeholder could be used to handle the commands
        -- `lua ${file}` is equivalent to `lua %`.
        -- On windows, the symbol "%" alone doesn't works, so
        -- use "${relativeFile}" instead. Other vim placeholders can
        -- still used.
        lua = {
            -- JustRun replaces this placeholder automatically
            cmd = "lua ${file}"
        },

        build = {
            cmd = "go build .",
            desc = "Build the project",
            cwd = "./src",
            exit_on_success = true
        },

        deploy = {
            run_before = { "build" },
            cmd = "echo 'Deploying...'"
        },

        run_args = {
            -- Joins with space: "python main.py --verbose --dry-run"
            cmd = {"python", "main.py", "--verbose", "--dry-run"},
            sep = " ", -- Custom separator for the cmd list
        },

        -- Default Separator (&&)
        build_all = {
            -- Joins with &&: "cd build && cmake .. && make"
            cmd = {"cd build", "cmake ..", "make"}
        },

        -- cmd could be a function to return a string | string[] | JustTask
        -- Example: Manual string concatenation (Hard way)
        dynamic_cmd = {
            cmd = function()
                local cmd = ""
                for i=1, 5 do
                    if i ~= 5 then
                        cmd = cmd .."echo '" .. i .. "';"
                    else
                        cmd = cmd .. "echo '" .. i .. "'"
                    end
                end
                return cmd
            end
        },

        -- Equivalent to dynamic_cmd but using table/list (Easy way)
        dynamic_cmd_with_sep = {
            cmd = function()
                local cmd_list = {}
                for i=1, 5 do
                    table.insert(cmd_list, "echo '" .. i .. "'")
                end
                return cmd_list
            end,
            sep = "; " -- Custom separator for the list
        }
    })
<

                                                             *justrun-commands*
2. Commands ~

:JustRun [task_name]                                                 *:JustRun*
    Runs the specified task. If no argument is provided, runs the default task
    configured in setup (default: "default").

:JustRunFind                                                       *:JustRunUi*
    Opens a selection menu using `vim.ui.select` with all available tasks found
    in the configuration file and filetypes task if `show_filetype_tasks` are 
    enabled.

:JustRunLast                                                   *:JustRunLast*
    Re-runs the last successfully executed task. Useful for TDD loops.

:JustRunUnderCursor                                     *:JustRunUnderCursor*
    Runs the task definition under the cursor. Must be triggered while editing
    the `.justrun.lua` file. Requires nvim-treesitter.



===============================================================================
                                                               *justrun-config*
3. Configuration ~

You can configure the plugin via the setup function:
>lua
    require("justrun").setup({
        filename = ".justrun.lua",   -- File to load tasks from
        filetype = {},               -- Table with tasks to run filetypes
        show_filetype_tasks = false, -- Show the filetype tasks on find menu
        default_task = "default",    -- Default task name
        cwd = ".",                   -- Default working directory
        force_run = false,           -- Run first task if default missing
        split_direction = "vertical",-- "vertical" or "horizontal"
        split_size = 50,             -- Size of the split
        exit_on_success = false,     -- Close terminal on success (code 0)
        default_sep = "&&",          -- Separator for command chaining
        max_depth = 20,              -- Max recursion depth for nested tasks
    })
<



===============================================================================
                                                                *justrun-tasks*
4. Task Configuration Fields: ~

    cmd             (string|string[]|function) The command to execute.
    run_before      (table) List of task names to run before the current one.
    cwd             (string) Working directory for the task.
    sep             (string) Separator used to join items if `cmd` is a list.
                    Defaults to `default_sep` config (usually "&&").
                    Useful to join arguments with " " (space).
    exit_on_success (boolean) Close terminal if exit code is 0.
    desc            (string) Description for the UI menu.

                                                         *justrun-placeholders*
5. Placeholders ~

You can use placeholders in your commands to make them dynamic. JustRun
supports both VSCode-style variables and standard Vim filename modifiers.

VSCode Style Variables (Recommended for cross-platform compatibility):

    ${file}                      Absolute path of the current file.
                                 Example: /home/user/project/src/main.py

    ${fileNoExtension}           Absolute path of the current file without
                                 extension.
                                 Example: /home/user/project/src/main.py

    ${fileBasename}              Filename with extension.
                                 Example: main.py

    ${fileBasenameNoExtension}   Filename without extension.
                                 Example: main

    ${fileDirname}               Directory containing the file.
                                 Example: /home/user/project/src

    ${relativeFile}              File path relative to the project root.
                                 Example: src/main.py

    ${workspaceFolder}           Root directory of the project (CWD).
                                 Example: /home/user/project

Vim Native Modifiers:

    You can also use standard Vim modifiers like `%`, `%:p`, `%:t`, `%:r`.
    See |filename-modifiers| for the full list.

    NOTE regarding Windows: ~
    On Windows, the `%` character is used for environment variables (e.g.,
    %PATH%). To prevent conflicts, JustRun disables the usage of the bare `%`
    symbol on Windows systems.

    If you need cross-platform support, strictly use `${file}` or
    `${relativeFile}` instead of `%`. Modifiers like `%:p` or `%:t` still work
    on all systems.

    Example: >lua
        -- Good (Works everywhere)
        cmd = "python ${file}"

        -- Good (Vim style, works everywhere)
        cmd = "python %:p"

        -- Risky (Might fail on Windows)
        cmd = "python %"
<

                                                            *justrun-filetypes*
6. Filetypes ~

Each file has a corresponding filetype, JustRun can run files using the
filetype inference by neovim api. Using this powerfull tool, you can run any
filetype wich neovim can to identify. The command `:JustRunFile` can be used to
run the current file (if no provide arguments) or a specific file (provide
argument). See the |ftplugin-docs| to see all filetypes supported by neovim.

    Example: >lua
        -- The task must has a name equals the current filetype
        python = {
            cmd = "python ${file}",
            desc = "Run the current python file"
        },

        -- Use :JustRunFile to run the current file. The JustRun will runs
        -- this task if the current filetype is 'lua'.
        lua = {
            cmd = "lua ${file}",
            desc = "Run the current lua file"
        }
<
